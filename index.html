Notifications sur ce téléphone

Copie ce code et colle-le dans le secret GitHub WEBPUSH_SUBSCRIPTION. Il identifie ce téléphone, ne le partage pas.

Quand les alertes partent

Signal confirmé : à la première mise à jour après la clôture US, vers 22:20 heure de Paris, parfois jusqu’à 30 min plus tard selon la charge de GitHub. Par push et par e-mail.

Pré-alerte : dans la dernière heure de séance, si le signal se formerait à la clôture au cours actuel. Elle n’est pas une confirmation.

Règle identique à ton indicateur TradingView : deux clôtures consécutives du même côté de la 200 SMA, clôture dans le sens du croisement, un seul signal par changement de tendance.

Clé d’alerte

À faire une seule fois, à l’installation. Génère la clé, colle-la dans le secret GitHub VAPID_PRIVATE_KEY, puis relance la mise à jour. Elle est créée sur ce téléphone et n’est envoyée nulle part.
